## Coordinate a Code Review
### How to access R notebooks 
Each grant has a folder on our repo. Within these folders, you will find R notebooks for various analyses or manuscript relevant to thet grant.  
### How to Run Notebooks
Across all notebooks, code chunks that rely on data sources located behind the VA firewall will not run on non-VA machines. However, code chunks that depends only on data available in our GitHub repositories can be executed on non-VA machines. Detailed instructions on how to establish connections and load data are provided in the respective notebooks.
